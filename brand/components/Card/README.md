# Card

Contenedor base del sistema: `surface` sobre `bg`, `radius-xl`, padding `space-8`, `shadow-card` y 18px entre elementos.

- Abre con una etiqueta `label` (Sora 600, 13px, MAYÚSCULAS, tracking 0.06em, en `muted`).
- Variante destacada: fondo `primary`, etiqueta en `on-primary-muted` y texto en `on-primary`. Úsala para una sola idea por vista (el eslogan).
- Se colocan en una cuadrícula de 4 columnas con gap `space-6`; las tarjetas del board ocupan 2 columnas.
- El consumidor aporta la etiqueta y el contenido.
